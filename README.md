# نظام أوزو OZO — نقاط البيع والمحاسبة

نظام إدارة كامل للكافيه يعمل محليًا على جهازك: بيع (POS)، مخزون، مشتريات، مصروفات، تقارير، مستخدمون بصلاحيات، نسخ احتياطي واستعادة، و**منيو + رمز QR** للعملاء.

واجهة عربية بالكامل (RTL) بتصميم متجاوب يعمل على الكمبيوتر والتابلت والموبايل، والعملة **جنيه مصري**.

---

## المتطلبات

- **Node.js** إصدار 18 أو أحدث (طُوّر على v24)
- متصفح **Chrome** (اختياري — فقط لتشغيل اختبار الواجهة)
- لا يحتاج إنترنت بعد التثبيت (الخط Cairo يُحمَّل من Google Fonts مع بديل تلقائي)

## التثبيت والتشغيل

```bash
npm install
npm start
```

ثم افتح المتصفح على: **http://localhost:3000**

- قاعدة البيانات تُنشأ تلقائيًا في `data/cafe.db` عند أول تشغيل.
- للاستخدام من الموبايل/التابلت على نفس شبكة Wi-Fi: افتح الرابط الذي يظهر عند التشغيل تحت جملة "من شبكة Wi-Fi (موبايل)" مثل `http://192.168.1.5:3000` (إن لم يعمل، اسمح لـ Node بالمرور عبر جدار حماية Windows).
- التغيير على المتغيرات البيئية (اختياري):
  - `PORT` — منفذ الخادم (الافتراضي `3000`)
  - `POS_DB_PATH` — مسار ملف قاعدة البيانات

## إنشاء حساب المدير الأول (خطوة إلزامية)

عند أول فتح للموقع ستظهر شاشة **إنشاء حساب المدير**:

1. اكتب اسم المستخدم (مثل `admin`) والاسم الكامل
2. اختر كلمة مرور قوية واكتبها مرتين
3. اضغط **إنشاء الحساب** — سيتم تسجيل دخولك تلقائيًا إلى لوحة التحكم

> لا توجد أي بيانات تجريبية في قاعدة البيانات. يبدأ النظام بالأصناف الافتراضية (تصنيف "بطاطس" + 13 صنفًا بأسعارها) دون أي مواد خام أو حركات.

## الأدوار والصلاحيات

| الصلاحية | المدير (Admin) | الكاشير (Cashier) |
| --- | :-: | :-: |
| نقطة البيع (POS) | ✔ | ✔ |
| الفواتير | ✔ | ✔ |
| المنتجات | ✔ | ✔ |
| لوحة التحكم والتقارير | ✔ | ✘ |
| المخزون / المشتريات / المصروفات | ✔ | ✘ |
| المستخدمون والإعدادات والنسخ الاحتياطي | ✔ | ✘ |

إدارة المستخدمين من **المستخدمون ← + مستخدم جديد** (دور وحالة نشط/موقوف).

## البيع وتكلفة المنتج

- تُضاف المكونات باسم/وحدة/سعر شراء، ثم يُحدَّد لكل منتج **وصفة** (مكونات وكميات). التكلفة تُحسب تلقائيًا من الوصفة = Σ (الكمية × سعر شراء المكوّن).
- عند البيع يُخصم المخزون حسب الوصفة داخل معاملة واحدة، مع أرقام فواتير تسلسلية `INV-XXXXXX`.
- الإلغاء أو الاسترجاع يعكس حركات المخزون تلقائيًا.

## النسخ الاحتياطي والاستعادة

من **الإعدادات → النسخ الاحتياطي**:

- **إنشاء نسخة احتياطية** — تُحفظ في `backups/` وتظهر في القائمة
- **استعادة نسخة** — تُستبدل قاعدة البيانات الحالية من النسخة المختارة (يُعاد تحميل الصفحة)
- **تصدير البيانات** — ملف JSON شامل (كامل المحتوى)

## المنيو والـ QR للعملاء

من **الإعدادات ← المنيو والـ QR**:

- صفحة منيو عامة للعملاء بلا تسجيل دخول تُفتح على **http://<الجهاز>:3000/menu** وتعرض الأصناف النشطة بأسعارها وتصنيفاتها مع بحث.
- الحقل **رابط المنيو** يُملأ تلقائيًا بأول روابط الشبكة المناسبة للموبايل؛ يستخدمه الـ QR.
- زر **👁 معاينة المنيو** يفتح الصفحة، وزر **⬇ تحميل الـ QR** يحفظ الكود كملف SVG للطباعة — ضعه على الطاولات ليفتح العميل المنيو مباشرة بموبايله.
- يعمل على الشبكة المحلية فقط (Wi-Fi): يجب أن يكون الجهاز والموبايل على نفس الشبكة، والحقل يُملأ تلقائيًا برابط IP الشبكة (وليس localhost) حتى تفتحه أجهزة العملاء — إن لم يفتح المنيو على الموبايل، فتأكد أن الجهاز والموبايل على نفس الـ Wi-Fi واسمح لـ Node بالمرور عبر جدار حماية Windows.

## الاختبارات

```bash
npm test          # اختبار واجهة الـ API الكاملة (128 فحصًا)
node test/browser.mjs   # اختبار المتصفح الفعلي عبر Chrome (70 فحصًا)
```

اختبار المتصفح يشغّل خادمًا خاصًا بقاعدة بيانات مؤقتة (منفذ 3100) ويغلقها تلقائيًا، ويتحقق من: الإعداد الأول، الدخول/الخروج، شاشة البيع، إصدار فاتورة وطباعتها، الصفحات الإدارية، كل التقارير، صلاحيات الكاشير، واجهة الموبايل 390px، وصفحة المنيو للعملاء (عرض الأصناف والبحث والتصنيفات).
